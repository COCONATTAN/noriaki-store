# Noriaki SHOP

เว็บไซต์ร้านค้าดิจิทัลสำหรับจำหน่ายชุดไฟล์อีโมจิ Discord

## Tech stack
- Node.js
- Express
- EJS
- Helmet

## Run locally
```bash
npm install
npm start
```

The app listens on the port provided by the hosting platform (default: 3000).

## Health check
Visit `/health` to confirm the web process is running.

## Current status
The first storefront foundation is in place. Authentication, database-backed products, wallet, checkout, protected downloads, payment verification, and admin tools are planned next. Do not accept payments or store real customer data until those systems are implemented and tested.
